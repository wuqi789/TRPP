Scout Mini Public Mock Demonstration Quick Reference
====================================================

This file covers only the public default chain. See README.md and SECURITY.md for complete module
boundaries, local adaptation, and security guidance.

1. Local variables
------------

Set these in the current shell; do not write real paths or credentials to the repository:

  export SCOUT_WORKSPACE=/path/to/scount-mini-ws-3
  export ISAACSIM_PYTHON_EXE=/path/to/isaacsim/python.sh

2. Build
-------

  cd "$SCOUT_WORKSPACE"
  source /opt/ros/humble/setup.bash
  colcon build --symlink-install --base-paths \
    llmModule/Interfaces groundingdinoVLM/src src/neupan_ros2/src \
    src/scout_ros2/scout_msgs
  source install/setup.bash

Do not copy build, install, or log directories from another host; rebuild after migration.

3. Run
-------

  cd "$SCOUT_WORKSPACE"
  ./run_traversal_system.sh headless:=true use_rviz:=false

The default is SCOUT_PUBLIC_BACKEND=mock and does not read credentials. To run with a window:

  ./run_traversal_system.sh headless:=false use_rviz:=true

4. Checks
-------

  ros2 topic hz /odom
  ros2 topic hz /scan_raw
  ros2 run tf2_ros tf2_echo map base_link
  ros2 topic echo /semantic_navigation/status

The sole acceptance condition is that the robot actually follows the fixed waypoints through the
curtain in Isaac and finally publishes SUCCEEDED.

5. Local hardware / real backend
--------------------------------

Physical LiDAR IPs, CAN devices, provider endpoints, model paths, and credentials are private local
configuration. This file does not provide real-backend startup parameters; external adapters must
first satisfy the interface and security requirements in README.md.
