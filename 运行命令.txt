Scout Mini 公开 mock 演示运行速查
===================================

本文件只给出公开默认链路。完整模块边界、本机适配和安全说明见 README.md 与 SECURITY.md。

1. 本机变量
------------

在当前 shell 设置，不要把实际路径或凭据写入仓库：

  export SCOUT_WORKSPACE=/path/to/scount-mini-ws-3
  export ISAACSIM_PYTHON_EXE=/path/to/isaacsim/python.sh

2. 构建
-------

  cd "$SCOUT_WORKSPACE"
  source /opt/ros/humble/setup.bash
  colcon build --symlink-install --base-paths \
    llmModule/Interfaces groundingdinoVLM/src src/neupan_ros2/src \
    src/scout_ros2/scout_msgs
  source install/setup.bash

不要复制其他主机的 build、install、log；迁移后重新构建。

3. 运行
-------

  cd "$SCOUT_WORKSPACE"
  ./run_traversal_system.sh headless:=true use_rviz:=false

默认 SCOUT_PUBLIC_BACKEND=mock，不读取凭据。带窗口运行可改为：

  ./run_traversal_system.sh headless:=false use_rviz:=true

4. 检查
-------

  ros2 topic hz /odom
  ros2 topic hz /scan_raw
  ros2 run tf2_ros tf2_echo map base_link
  ros2 topic echo /semantic_navigation/status

唯一验收条件：Isaac 中的小车实际沿固定 waypoint 穿过门帘，并最终发布 SUCCEEDED。

5. 本机硬件/正式后端
---------------------

实体 LiDAR IP、CAN 设备、provider endpoint、模型路径和凭据都属于本机私有配置。本文件
不提供正式后端启动参数；外部 adapter 必须先满足 README.md 中的接口和安全要求。
